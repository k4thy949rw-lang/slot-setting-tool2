スマスロ設定判別ツール（PWAファイル一式）

含まれるファイル
- index.html：アプリ本体
- manifest.json：ホーム画面アプリ設定
- service-worker.js：オフライン表示用キャッシュ
- icon.svg：アプリアイコン

公開手順（無料ホスティングサービスを利用）
1. ZIPを展開します。
2. GitHubアカウントを用意し、新しい公開リポジトリを作成します。
3. このフォルダ内の4ファイルをリポジトリのルートへアップロードします。
4. リポジトリの Settings > Pages で公開元を設定し、公開URLが発行されるのを待ちます。
5. iPhoneのSafariで公開URLを開き、共有ボタン >「ホーム画面に追加」を選びます。
   iOSのバージョンによって表示文言が異なる場合があります。

注意
- このZIP自体はまだインターネットに公開されていません。公開URLの発行にはホスティングサービス上での操作が必要です。
- 実戦履歴はその端末・ブラウザのローカル保存です。別端末への自動同期はありません。
- 現時点では設定別の確率を正確に計算するための機種データは未登録です。誤った確率を表示しないよう、判定結果は実績と示唆の整理に限定しています。
- 設定示唆の選択肢は入力UIの例です。機種固有の示唆内容は最新の信頼できる解析情報で確認してから使用してください。
